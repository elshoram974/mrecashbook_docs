غوص في الميزات (Books & Entries) Features Deep Dive

شرح تفصيلي لكيفية عمل الميزات الأساسية: إدارة الدفاتر، تسجيل المعاملات، وتصدير التقارير. A detailed explanation of core features: managing books, recording transactions, and exporting reports.

📚 إدارة الكتب والارتباط بالـ DB Books Management & DB Binding

تبدأ الرحلة من `BooksDashboardScreen` حيث يتم جلب البيانات بشكل حي (Reactive). كل `BookCard` ليس مجرد تصميم، بل هو كائن يستشعر حالة "الخصوصية" (Privacy Mode) ليخفي الأرقام إذا لزم الأمر.

The journey starts at `BooksDashboardScreen` where data is fetched reactively. Each `BookCard` isn't just a design; it's an object that senses the "Privacy Mode" to hide numbers when necessary.

📁 lib/features/books/presentation/widgets/book_card.dart
return BlocBuilder(
  builder: (context, privacyState) {
    final isPrivacyActive = privacyState.isBalanceHidden;
    return Text(
      isPrivacyActive ? '***' : balance.toStringAsFixed(2),
    );
  },
);
💡

لاحظ استخدام `CustomPaint` في `BookCard` لرسم الحواف المقطعة (Dashed Border) للكتب المستبعدة من المجموع الكلي.

Note the use of `CustomPaint` in `BookCard` to draw dashed borders for books excluded from the global total.

📓 دفتر العمليات (Entries Ledger) Entries Ledger

عند فتح أي كتاب، ننتقل لـ `EntriesScreen`. هنا نستخدم `EntriesCubit` الذي يدير عمليات معقدة مثل: البحث، الفلترة حسب النوع، وتحديد عمليات متعددة (Bulk Selection) للحذف أو النسخ.

When opening a book, we go to `EntriesScreen`. Here, `EntriesCubit` manages complex operations like searching, filtering by type, and bulk selection for deleting or copying.

🔍 نظام الفلترة الخارق (Advanced Filters) Super Filter System

التطبيق يدعم فلترة متقدمة جداً تسمح للمستخدم بالبحث داخل "الحقول المخصصة" (Custom Fields). هذا يتم عبر `CustomFilterBottomSheet` الذي يرسل النتائج للـ Cubit لتحديث الـ UI فوراً.

The app supports advanced filtering inside "Custom Fields". This is done via `CustomFilterBottomSheet`, which sends results to the Cubit to update the UI instantly.

📁 lib/features/books/presentation/widgets/entry_tile.dart
// عرض حقل مخصص داخل العملية
if (item.fields.isNotEmpty)
  Wrap(
    spacing: 4,

📊 تصدير التقارير (PDF Export) PDF Exporting

أحد أصعب الأجزاء كان تحويل الجدول الملون والمعقد إلى ملف PDF احترافي. نستخدم مكتبة `pdf` مع `PdfExportHelper` لتوليد مستند يحتوي على ترويسة (Header) بملخص الحساب وجدول منظم بجميع العمليات.

One of the hardest parts was converting complex, colorful tables into professional PDFs. We use the `pdf` package with `PdfExportHelper` to generate documents with headers, summaries, and organized tables.

⚠️

تصدير الـ PDF يدعم اللغة العربية بشكل كامل (RTL) عبر تحميل خطوط مخصصة تدعم اليونيكود العربي، وهو تحدي كبير في تطبيقات Flutter.

PDF export fully supports Arabic (RTL) by loading custom fonts that support Arabic Unicode, a significant challenge in Flutter apps.
