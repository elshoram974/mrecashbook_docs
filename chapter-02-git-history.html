🏷️ إعادة التسمية (Rebranding) The Rebranding Phase

في مرحلة متقدمة، تم تغيير اسم التطبيق من `Ledger` إلى `MRE CashBook`. هذه الخطوة لم تكن مجرد تغيير نص، بل شملت تغيير الـ Package Name، أيقونات التطبيق، ومسارات الحفظ في الموبايل.

At an advanced stage, the app name was changed from `Ledger` to `MRE CashBook`. This wasn't just a text change—it involved updating the Package Name, app icons, and file storage paths.

📁 pubspec.yaml (Commit: 5690f370)
- name: ledger
+ name: mre_cashbook
📁 lib/core/config/app_config.dart (Commit: 5690f370)
- static const String appName = 'Ledger';
+ static const String appName = 'MRE CashBook';
PRODUCT_BUNDLE_IDENTIFIER = net.mrecode.mrecashbook;
🔍 بيعمل إيه؟ 🔍 What does it do?

بيغير المعرف الفريد للتطبيق على المتجر (App ID).

Changes the unique identifier of the app on the store (App ID).

❓ لو حذفناه؟ ❓ What breaks if removed?

المتجر هيعتبره تطبيق مختلف تماماً ومش هيحدث التطبيق القديم.

The store would treat it as a new app and won't update the old one.

⚠️

تغيير الـ Package Name في منتصف المشروع يتطلب حذراً شديداً لأنه بيأثر على خدمات Firebase و الـ Method Channels.

Changing the Package Name mid-project requires extreme caution as it affects Firebase services and Method Channels.
