التصاميم ونظام الألوان (UI & Theming) UI & Theming System

فلسفة التصميم في المشروع: كيف نبني واجهات بريميوم باستخدام "الثوابت المركزية" و "Material 3". Design philosophy: Building premium UIs using centralized constants and Material 3.

📏 مبدأ: لا أرقام سحرية (No Magic Numbers) Principle: No Magic Numbers

في هذا المشروع، يمنع منعاً باتاً كتابة أرقام للمسافات أو الحواف مباشرة داخل الويدجت. نستخدم كلاس `AppSizes` لضمان تناسق الشكل في كل التطبيق.

In this project, it's strictly forbidden to hardcode spacing or radius values inside widgets. We use the `AppSizes` class to ensure visual consistency across the entire app.

📁 lib/core/constants/app_sizes.dart
class AppSizes {
  static const double p16 = 16;      // للبادينج
  static const double radiusMd = 16; // للحواف المستديرة
}
💡

نفصل بين الثوابت "دلالياً" (Semantically)؛ حتى لو كان البادينج والحواف كلاهما 16، نستخدم اسمين مختلفين ليسهل التعديل لاحقاً.

We separate constants semantically; even if padding and radius are both 16, we use different names to allow independent updates later.

🎨 ألوان مخصصة: `ThemeExtension` Custom Colors: ThemeExtension

نظام Flutter المدمج لا يوفر أسماء ألوان مثل `income` أو `expense`. لذا نستخدم `ThemeExtension` لإضافة هذه المسميات دالة المعنى لنستخدمها لاحقاً عبر الـ context.

Flutter's built-in system doesn't provide color names like `income` or `expense`. So we use `ThemeExtension` to add these semantic names, accessible via context.

📁 lib/core/theme/app_colors_extension.dart
class AppColorsExtension extends ThemeExtension {
  final Color income;
  final Color expense;
  // ... copyWith & lerp
}
🌙 الوضع الليلي الاحترافي Professional Dark Mode

الوضع الليلي ليس مجرد "أسود". نستخدم درجات متباينة بعناية (Contrast) مثل `0xFF1E1E2C` لتوفير راحة للعين مع الحفاظ على فخامة الواجهة.

Dark mode isn't just "black". We use carefully chosen contrasting shades like `0xFF1E1E2C` to provide eye comfort while maintaining a premium feel.

📁 lib/core/theme/app_theme.dart
static ThemeData _build(Brightness brightness, AppColorsExtension ext) {
  final ColorScheme cs = ColorScheme.fromSeed(...);
  return ThemeData(
    useMaterial3: true,
    extensions: [ext],
    // تخصيص الأزرار، الحقول، والجداول
  );
}

🔍 كيف نستخدمها؟🔍 How to use it?

بفضل الـ Extension على `BuildContext` في ملف `context_extension.dart`؛ يمكننا الوصول لأي لون مخصص بسهولة وسرعة.

Thanks to our `BuildContext` extension, we can access any custom color quickly and easily.
