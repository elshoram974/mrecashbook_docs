الفصل الثاني عشر: التكامل مع Firebase Chapter 12: Firebase Integration

كيف نستخدم سحابة Google لتقوية التطبيق وتعقب الأخطاء والوصول للمستخدمين.

🔥 الدور الحيوي لـ Firebase The Vital Role of Firebase

فيربيز مش مجرد قاعدة بيانات، هي منظومة كاملة بتساعدنا في 3 حاجات أساسية:

1
Stability (الاستقرار)

معرفة لو التطبيق "كرش" (Crashed) عند حد من المستخدمين قبل ما يشتكي.

2
Connectivity (التواصل)

إرسال إشعارات فورية (Push Notifications) لجذب المستخدمين للعودة للتطبيق.

3
Configuration (التحكم عن بُعد)

تغيير بعض إعدادات التطبيق بدون الحاجة لعمل تحديث جديد على المتجر.

⚡ التجهيز الذكي (Safe Initialization) Resilient Firebase Setup

مش كل الموبايلات فيها خدمات جوجل (GMS). موبايلات هواوي الجديدة مثلاً لو حاولت تشغل فيربيز عليها بشكل عادي، التطبيق ممكن "يهنج" (Hang) تماماً. عشان كدة استعملنا تقنية الـ Resilience:

main.dart
await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
).timeout(
  const Duration(seconds: 3),
  onTimeout: () => throw Exception('Firebase timeout'),
);
timeout(Duration(seconds: 3))
ليش التايم أوت؟Why Timeout?
وقت كافي جداً للموبايل الطبيعي. لو خد وقت أطول، غالباً السيرفر محجوب أو الموبايل معندوش GMS، فبنعمل Skip ونفتح التطبيق عادي.To prevent app freeze on non-GMS devices. If it stalls, we skip and let the app run offline.
🐞 تعقب الأخطاء: Crashlytics Real-time Bug Monitoring

فيربيز بتبعت لنا تقرير فوري بكل "كرش" (Crash) أو خطأ برمجي يحصل.

graph LR User[User Device] -- Error Occurs --> SDK[Crashlytics SDK] SDK -- Background Upload --> Console[Firebase Console] Console -- Alert --> Engineering[Engineering Team]
Logging Errors
FlutterError.onError = (details) {
  FirebaseCrashlytics.instance.recordFlutterError(details);
};

ملاحظة: إحنا بنفعل الـ Crashlytics في الـ Release Mode بس، عشان ما نملأش السيرفر ببيانات وتجارب المبرمجين وقت التطوير.

🔔 الإشعارات: Cloud Messaging (FCM) Dynamic Notifications Flow

التطبيق بيقدر يستلم إشعارات حتى لو هو مقفول تماماً (Terminated State).

StateHandlerBehavior
ForegroundonMessageShow in-app banner
BackgroundonMessageOpenedAppGo to specific screen
TerminatedgetInitialMessageResume with payload
Background Message Handler
@pragma('vm:entry-point')
Future firebaseMessagingBackgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
  print("Handling a background message: ${message.messageId}");
}

Entry Point: لازم الـ Handler يكون @pragma('vm:entry-point') عشان نظام التشغيل يقدر يشغله في Process منفصل لو التطبيق مقفول.

📱 استراتيجية دعم هواوي (Huawei HMS) Handling Non-GMS Environments

في MRE CashBook، إحنا عاملين حساب أجهزة هواوي (AppGallery). لو فيربيز ما اشتغلش:

1
Silent Fail

التطبيق مش بيدي Error للمستخدم، بيكمل تشغيله في وضع الـ Local Mode فقط.

2
Local Backup

بنعتمد على حفظ البيانات في الـ Storage الداخلي كبديل آمن.

⚙️ الإعدادات: firebase_options.dart The Modern Config Approach

بدل ما نعتمد على ملفات الـ JSON والـ Plist، الطريقة الجديدة بتخلي كل الإعدادات في كود Dart.

static const FirebaseOptions android = FirebaseOptions(
  apiKey: '...',
  appId: '...',
  messagingSenderId: '...',
  projectId: '...',
  storageBucket: '...',
);

ده بيسهل دعم الـ Web والـ Desktop في نفس المشروع بدون تعقيد.

❓ أسئلة هندسية عن Firebase Firebase Engineering FAQ
هل استخدام فيربيز مجاني؟
Is Firebase free?
خدمات الـ Crashlytics والـ Cloud Messaging مجانية تماماً وبدون حدود، وده سبب اختيارنا ليها في MRE CashBook.
هل فيربيز بيشوف بياناتي المالية؟
Can Firebase see my financial data?
لا، إحنا مش بنحفظ الداتابيز (Drift) على فيربيز. إحنا بنستخدمه للقنوات الجانبية بس (أخطاء، إشعارات).
