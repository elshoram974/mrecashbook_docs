⚡ التجهيز الذكي (Safe Initialization) Defensive Firebase Initialization

مش كل الموبايلات فيها خدمات جوجل (GMS). موبايلات هواوي الجديدة مثلاً لو حاولت تشغل فيربيز عليها بشكل عادي، التطبيق ممكن "يهنج" (Hang) في البداية. عشان كدة استعملنا الـ Timeout:

main.dart
await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
).timeout(
  const Duration(seconds: 3),
  onTimeout: () => throw Exception('Firebase timeout'),
);
timeout(Duration(seconds: 3))
ليش 3 ثواني؟Why 3s?
وقت كافي جداً للموبايل الطبيعي إنه يربط بالسيرفر. لو خد وقت أطول، غالباً الموبايل معندوش GMS، فبنعمل Skip ونفتح التطبيق عادي بدل ما المستخدم يفضل مستني للأبد.Enough for normal devices. If it takes longer, the device likely lacks GMS, so we skip to avoid hanging.
🐞 تعقب الأخطاء: Crashlytics Error Tracking with Crashlytics

بدل ما نستنى المستخدم يكلمنا يقولنا "التطبيق قفل"، فيربيز بتبعت لنا تقرير فوري بكل "كرش" (Crash).

graph LR User[User Device] -- Error Occurs --> Log[Crashlytics SDK] Log -- Background Upload --> Server[Firebase Console] Server -- Notification --> Dev[Developer]
Enable in Release Only
await FirebaseCrashlytics.instance.setCrashlyticsCollectionEnabled(
  kReleaseMode, // مش عاوزين وجع دماغ في الـ Debug
);

نصيحة: إحنا بنربط الـ Crashlytics بالـ FlutterError.onError عشان يمسك أي خطأ يحصل في الـ Widgets حتى لو التطبيق ما قفلش تماماً.

🔥 لماذا فيربيز (Firebase)؟ Why Firebase?

الإشعارات بتوصل حتى لو التطبيق مقفول، بفضل الـ Background Handlers.

1

المراقبة: معرفة لو التطبيق "كرش" (Crashed) عند حد من المستخدمين فوراً.

2

التواصل: إرسال إشعارات للمستخدمين بالمميزات الجديدة أو النصائح المالية.

3

التحليلات: فهم إزاي المستخدمين بيتفاعلوا مع التطبيق عشان نطوره.
