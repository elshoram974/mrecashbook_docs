التنقل المتكيف (Adaptive Navigation) Responsive Navigation

كيف يتحول التطبيق من `BottomNavigationBar` في الموبايل إلى `NavigationRail` في التابلت مع الحفاظ على تجربة مستخدم سلسة. How the app transitions from a BottomNavigationBar on mobile to a NavigationRail on tablets while maintaining a smooth UX.

📱💻 كلاس `ResponsiveLayout` The ResponsiveLayout Class

بدلاً من تكرار كود التحقق من حجم الشاشة في كل مكان، أنشأنا ويدجت مخصصاً يقوم بهذه المهمة بذكاء مع تأثير (Transition) ناعم عند تغيير حجم النافذة.

Instead of repeating screen size checks everywhere, we created a custom widget that handles this smartly with a smooth fade transition when resizing.

📁 lib/core/utils/responsive/responsive_layout.dart
return LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth >= AppSizes.mobileBreakpoint) {
      return tabletBody ?? mobileBody;
    }
    return mobileBody;
  },
);
💡

نستخدم `AnimatedSwitcher` حول الجسم (Body) لضمان عدم حدوث قفزة مفاجئة عند الانتقال بين وضع الموبايل والتابلت.

We use `AnimatedSwitcher` around the body to prevent a sudden jump when switching between mobile and tablet modes.

🏗️ المنظم: `MainScreen` The Orchestrator: MainScreen

شاشة الـ `MainScreen` هي المسؤولة عن تنظيم التنقل بين الشاشات الثلاث الرئيسية: الكتب، الإحصائيات، والإعدادات. هي التي تقرر شكل شريط التنقل بناءً على نوع الجهاز.

The `MainScreen` is responsible for organizing navigation between the three main screens: Books, Analytics, and Settings. It decides the navigation UI based on the device type.

📁 lib/features/main/presentation/screens/main_screen.dart
ResponsiveLayout(
  mobileBody: Scaffold(
    bottomNavigationBar: BottomNavigationBar(...),
  ),
  tabletBody: Scaffold(
    body: Row(
      children: [
        NavigationRail(...),
        Expanded(child: bodyContent),
      ],
    ),
  ),
)
💾 حفظ حالة الشاشات: `IndexedStack` Preserving State: IndexedStack

من الأخطاء الشائعة هي تدمير الشاشة وإنشاؤها من جديد عند التنقل. لحل ذلك، نستخدم `IndexedStack` الذي يبقي كل الشاشات في الذاكرة ويظهر واحدة فقط، مما يحافظ على موضع التمرير (Scroll Position) في كل صفحة.

A common mistake is destroying and recreating screens during navigation. To solve this, we use `IndexedStack`, which keeps all screens in memory but shows only one, preserving the scroll position of each page.

final bodyContent = IndexedStack(
  index: _selectedIndex,
  children: _screens,
);
