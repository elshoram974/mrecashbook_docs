الأمان والخصوصية (Security) Security & Privacy

لأن البيانات المالية حساسة، قمنا ببناء نظام أمان متعدد الطبقات يحمي خصوصية المستخدم وبياناته. Since financial data is sensitive, we built a multi-layered security system to protect user privacy.

🔐 قفل التطبيق (Biometric Lock) App Lock (Biometrics)

باستخدام مكتبة `local_auth`؛ نوفر للمستخدم خاصية قفل التطبيق عبر البصمة أو الوجه (FaceID). عند تفعيل هذه الخاصية، يظهر `AuthGuardScreen` كبوابة دخول إجبارية.

Using the `local_auth` package, we provide an app lock feature via fingerprint or face ID (FaceID). When enabled, the `AuthGuardScreen` acts as a mandatory entry gate.

📁 lib/features/auth/presentation/screens/auth_guard_screen.dart
Future _authenticate() async {
  final success = await context.read().authenticate();
  if (success) {
    Navigator.of(context).pushReplacement(...);
  }
}
👁️‍🗨️ وضع الخصوصية (Privacy Mode) Privacy Mode

أحد أذكى الميزات هي "إخفاء المبالغ". بضغطة زر واحدة من الإعدادات، يتم تحويل جميع الأرقام في التطبيق إلى نجوم `***`؛ مما يسمح للمستخدم بفتح التطبيق في الأماكن العامة دون القلق من المتسللين.

One of the smartest features is "Hide Amounts". With one tap, all numbers in the app turn into asterisks `***`, allowing users to open the app in public without privacy worries.

📁 lib/core/preferences/app_preferences_cubit.dart
Future togglePrivacy() async {
  final newValue = !state.isBalanceHidden;
  await _prefs.setBool('is_balance_hidden', newValue);
  emit(state.copyWith(isBalanceHidden: newValue));
}
🛡️ حماية البيانات (Data Protection) Data Security

التطبيق يعمل تماماً دون إنترنت (Offline-first)، مما يعني أن بياناتك لا ترفع على أي سيرفر خارجي، تظل محمية داخل جهازك فقط.

The app works completely offline (Offline-first), meaning your data is never uploaded to external servers; it remains protected on your device only.

💡

ندعم أيضاً خاصية "النسخ الاحتياطي اليدوي" (Manual Backup) المشفر؛ حيث يمكن للمستخدم تصدير قاعدة بياناته وحفظها في مكان آمن.

We also support manual encrypted backups; users can export their database and save it securely.
